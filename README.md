# 운영 대시보드

학생 실습 자료를 읽어 매출 비교, 행사 준비 현황, 예제 날씨를 보여주는 정적 웹앱입니다. 원본 실습 파일은 수정하지 않습니다.

## 실행

이 폴더에서 정적 파일 서버를 실행한 뒤 브라우저에서 엽니다. 예: `python -m http.server 4173` 후 `http://localhost:4173` 접속. 로컬 파일 직접 열기는 브라우저의 fetch 제한으로 지원하지 않습니다.

엑셀 읽기와 보고서 저장에는 SheetJS 브라우저 라이브러리를 jsDelivr CDN에서 불러오므로 첫 실행 때 인터넷 연결이 필요합니다.

## 기능

- 3개 원본 엑셀을 자동으로 읽어 필수 열과 채널을 검증하고, 480행을 통합합니다.
- 점포·채널·기준주·브랜드·장르 필터와 매출 KPI, 주간 비교, 상세 기록 검색을 제공합니다.
- `record_id`별 메모를 이 브라우저의 localStorage에 보관합니다.
- 선택된 조건으로 `04_보고양식.xlsx`의 열 순서에 맞춘 새 XLSX 보고서를 내려받습니다.
- 행사 준비 CSV의 점검 기준일을 사용해 미완료와 마감 구간을 분류합니다.
- 제공된 날씨 JSON 예제를 표시하고 실제 관측·예보가 아니라는 안내를 유지합니다.

## Vercel

프로젝트 루트가 이 폴더인 저장소를 Vercel에 연결해 정적 사이트로 배포합니다. 별도 빌드 명령은 필요하지 않습니다. 배포 시 `A_매출비교`, `C_행사준비`, `D_화면과연결` 입력 자료 경로를 그대로 포함해야 자동 로딩이 동작합니다.
