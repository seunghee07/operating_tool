# 운영 대시보드

학생 실습 자료를 읽어 매출 비교, 행사 준비 현황, 예제 날씨를 보여주는 정적 웹앱입니다. 원본 실습 파일은 수정하지 않습니다.

## 실행

PowerShell에서 `./tools/start-app.ps1`을 실행하고 `http://127.0.0.1:4173`을 엽니다. 번들 Python을 자동으로 사용하며, 없으면 PATH의 Python을 사용합니다. 종료는 Ctrl+C입니다. 로컬 파일 직접 열기는 브라우저의 fetch 제한으로 지원하지 않습니다.

엑셀 읽기와 보고서 저장에는 로컬 `vendor/xlsx.full.min.js`를 사용합니다. 원본 XLSX는 읽기 전용으로 사용하고 결과는 별도 다운로드합니다.

## 기능

- 3개 원본 엑셀을 자동으로 읽어 필수 열과 채널을 검증하고, 480행을 통합합니다.
- 점포·채널·기준주·브랜드·장르 필터와 KPI 3개, 점포별 비교, 상세 기록 검색을 제공합니다. 동일한 조회 조건이 KPI·차트·상세·보고서에 적용됩니다.
- `record_id`별 메모를 이 브라우저의 localStorage에 보관합니다.
- 선택된 조건으로 `04_보고양식.xlsx`의 열 순서에 맞춘 새 XLSX 보고서를 내려받습니다.
- 행사 준비 CSV의 점검 기준일을 사용해 미완료와 마감 구간을 분류합니다.
- 제공된 날씨 JSON 예제를 표시하고 실제 관측·예보가 아니라는 안내를 유지합니다.

## Vercel

원격 저장소는 `https://github.com/seunghee07/operating_tool.git`입니다. 별도 빌드 명령은 필요하지 않습니다. A~E 원본 폴더는 `.gitignore`로 제외되어 있으므로 GitHub만으로 배포하면 자동 입력 자료가 없습니다. 공개 허용된 교육용 샘플을 별도로 배포에 준비해야 합니다. 배포된 정적 자료는 공개 다운로드가 가능하므로 업무 원본과 실제 키를 포함하지 않습니다.

## 검사 결과

원본과 별도인 `results/`에 독립 집계, 보존 해시, 검사 보고서와 다운로드 검사 파일을 저장합니다. `results/verify-report.md`에서 수행한 검사와 남은 제한을 확인할 수 있습니다.
